# 🎲 Java Dice Roller

A simple console-based Dice Roller application built using Java. This program allows users to roll one or more dice, displays ASCII dice art for each roll, and calculates the total sum of all rolled dice.

## Features

* Roll multiple dice at once
* Random dice values between 1 and 6
* ASCII art representation of each dice face
* Calculates and displays the total sum
* Input validation for invalid dice count

## Technologies Used

* Java
* Scanner Class
* Random Class
* Switch Expressions
* Java Text Blocks

## How It Works

1. Enter the number of dice you want to roll.
2. The program generates random values from 1 to 6.
3. Dice art is displayed for each roll.
4. The value of each dice is shown.
5. The total sum of all dice is calculated and displayed.
